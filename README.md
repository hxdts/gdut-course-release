# 广工课表

广东工业大学教务系统的安卓客户端。**直接调用学校接口取数据**，不是网页套壳。

> 作者：hxdts ｜ 包名：`com.gdut.course` ｜ 版本：**2.0** ｜ 支持 Android 6.0+

## 功能

### 📅 课表

把一周的课画成网格，一眼看完。

| 能力 | 说明 |
| --- | --- |
| 按周查看 | 周一到周日 7 列，节次 1-14 行，跨节的课自动合并成一个色块 |
| **显示日期** | 表头每天带日期，今天的日期高亮成蓝色 |
| **直接选周** | 点顶部「第 N 周」弹出 22 周网格，点哪周跳哪周；左右箭头可微调前后一周 |
| 当前周自动定位 | 根据学期起始日期自动算出今天在第几周，打开就是本周 |
| **课程详情** | 点任意课程块，从底部弹出：上课时间（精确到几点几分）、地点、教师、周次、教学班、学时、人数 |
| 课程配色 | 同一门课始终同一种颜色，方便辨认 |
| 课程清单 | 课表下方列出本周所有课程及时间地点 |

**上课时间按广工官方作息表换算**（来源：《2022年第十八次校长办公会议纪要》）：

| 节次 | 时间 | 节次 | 时间 |
| --- | --- | --- | --- |
| 第1节 | 8:30-9:15 | 第7节 | 15:30-16:15 |
| 第2节 | 9:20-10:05 | 第8节 | 16:30-17:15 |
| 第3节 | 10:25-11:10 | 第9节 | 17:20-18:05 |
| 第4节 | 11:15-12:00 | 第10节 | 18:30-19:15 |
| 第5节 | 13:50-14:35 | 第11节 | 19:20-20:05 |
| 第6节 | 14:40-15:25 | 第12节 | 20:10-20:55 |

### 📊 成绩与绩点

- 平均学分绩点（GPA）大卡片
- 加权平均分、总学分统计
- 全部课程成绩列表，按分数自动配色（优秀绿 / 良好蓝 / 及格橙 / 不及格红）

### 🌐 英语四六级

走教务系统「考级成绩」接口。有记录就显示，没有会提示。

### 💪 体测成绩

走教务系统「体测成绩」接口。同上。

### 🎨 外观

- **壁纸**：「我的 → 外观 → 设置壁纸」，从相册选一张图。图片比例和屏幕不匹配时，空白区域会自动用**同一张图的模糊放大版**填充（毛玻璃效果），不会留白也不会拉伸变形
- **主题色**：7 种预设颜色（蓝/紫/绿/橙/粉/青/靛），点一下整个 App 的顶栏、按钮、高亮一起变

### 🔄 自动更新

- **每次启动自动检查**新版本，有新版本才弹窗打扰你
- **多源校验**：同时查 GitHub API、ghproxy、jsDelivr，取最高版本号，不会被单个 CDN 的缓存骗成"已是最新"
- 也支持**从手机本地文件更新**：随便拿到一个 apk，点「我的 → 从手机文件更新」选中即可

### 🔐 登录

- 输入学号 + 统一身份认证密码
- 复刻了金智 authserver 的 CAS 登录协议（含密码 AES-128-CBC 加密），不依赖网页
- 登录态会一直保持，**卸载重装才会要求重新登录**
- 会话过期时会主动提示并引导重新登录

## 数据从哪来

全部来自学校教务系统 `jxfw.gdut.edu.cn`，App 没有自己的后端：

| 数据 | 接口 |
| --- | --- |
| 菜单 | `default!getMenu.action` |
| 当前学期 | `xsgrkbcx!xsgrkbMain.action` |
| 课表 | `xsgrkbcx!getKbRq.action?xnxqdm=<学期>&zc=<周次>` |
| 课程成绩 | `xskccjxx!getDataList.action` |
| 考级成绩 | `xskjcjxx!getDataList.action` |
| 体测成绩 | `xstccjxx!getDataList.action` |
| 登录 | `authserver.gdut.edu.cn/authserver/login`（CAS） |

App 不保存密码，登录成功后只保留学校下发的会话 Cookie。所有请求都是你手机直接和学校服务器通信。

## 更新源（给维护者看）

`version.json`：

```json
{
  "versionCode": 11,
  "versionName": "2.0",
  "url": "https://gcore.jsdelivr.net/gh/hxdts/gdut-course-release@main/gdut-course-v12.apk",
  "urlMirror": ["...备用下载地址..."],
  "notes": "这一版改了什么"
}
```

发新版流程：上传新 apk（文件名带版本号）→ 改 version.json 的 `versionCode`/`url` → 删掉旧 apk。

> 文件名带版本号是为了绕开 jsDelivr 的 CDN 缓存；仓库只保留当前版本，避免堆积。
